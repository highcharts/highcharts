Iris flower dataset — scatterplot matrix

Multivariate dashboard exploring the Iris flower dataset. Every pair of measurements (sepal length, sepal width, petal length and petal width) is plotted against every other in a scatterplot matrix, with each point colored by species. The diagonal shows the distribution of each measurement as a histogram, and a data grid below lists the underlying values. All components share a single dataset with hover state synchronization (highlight sync) enabled.
