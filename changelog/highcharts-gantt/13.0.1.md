# Changelog for Highcharts Gantt v13.0.1 (2026-08-17)

- Most changes listed under Highcharts 13.0.1 above also apply to Highcharts Gantt 13.0.1.

## Bug fixes
- Fixed [#24855](https://github.com/highcharts/highcharts/issues/24855), `gantt` series in `navigator` rendered incorrectly on initial render.
- Fixed [#24849](https://github.com/highcharts/highcharts/issues/24849), x-axis start date was incorrect when start was not set on point.
- Fixed [#24644](https://github.com/highcharts/highcharts/issues/24644), loading Gantt module crashed after chart destroy.
