# Changelog for Highcharts Dashboards v4.2.3 (2026-09-29)

- Made `Board.update()` return a promise that resolves when all components have loaded their connectors and rendered. See [#25039](https://github.com/highcharts/highcharts/issues/25039).
- Security fixes. See [security advisories](https://github.com/highcharts/highcharts/security/advisories) for more details.

## Bug fixes
- Improved finding containers by id.
- Fixed [#25111](https://github.com/highcharts/highcharts/issues/25111), navigator remained after destroy.
- Fixed [#25092](https://github.com/highcharts/highcharts/issues/25092), passive events went undetected when listener options were copied.
- Fixed [#25082](https://github.com/highcharts/highcharts/issues/25082), sync was broken when destroyed charted.
