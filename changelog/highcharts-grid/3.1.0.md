# Changelog for Highcharts Grid v3.1.0 (2026-08-06)

- **Grid Pro:** Added support for [row grouping](https://www.highcharts.com/docs/grid/rows/grouping)
- **Grid Pro:** Optimized event options update.
- **Grid Pro:** Added `treeView` [data aggregation](https://www.highcharts.com/docs/grid/rows/tree-view#aggregation).
- **Grid:** Added support for [column virtualization](https://www.highcharts.com/docs/grid/columns/virtualization).
- **Grid:** Added built-in context menu groups.
- **Grid:** Grid filtering conditions allowlist.
- **Grid:** Added possibility to render Grid caption as HTML. See [#24683](https://github.com/highcharts/highcharts/issues/24683).
- **Grid:** Added support for runtime warnings when deprecated Grid options are used.
- **Grid:** Added support for [minWidth](https://api.highcharts.com/grid/columns.minWidth) and [maxWidth](https://api.highcharts.com/grid/columns.maxWidth) in column options. See [#24395](https://github.com/highcharts/highcharts/issues/24395).
- **Grid:** Added `data.dataTableKey` option to select a table from Grid data connectors.
- **Grid:** Refactored CSS by separating theme styles from functional styles.

## Bug fixes
- **Grid:** Fixed rows being pushed out of view when resizing a column while scrolled down, with variable row heights.
