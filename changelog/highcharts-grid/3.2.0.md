# Changelog for Highcharts Grid v3.2.0 (2026-09-18)
 
 - **Grid Pro:** Added the summary rows and columns feature.
 
 ## Bug fixes
 - **Grid Pro:** Fixed deeply nested formulas crashing the parser with a `RangeError` instead of failing with a regular parse error.
 - **Grid:** Fixed [#25133](https://github.com/highcharts/highcharts/issues/25133), handled missing row search columns.
 - **Grid:** Fixed [#25217](https://github.com/highcharts/highcharts/issues/25217), grid registry had broken ids after destroy.
 - **Grid:** Fixed ellipsis text overflow for tree view group column.
