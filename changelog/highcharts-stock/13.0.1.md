# Changelog for Highcharts Stock v13.0.1 (2026-08-17)

- Most changes listed under Highcharts 13.0.1 above also apply to Highcharts Stock 13.0.1.

## Bug fixes
- Fixed [#24858](https://github.com/highcharts/highcharts/issues/24858), initial rendering of grouped data was incorrect.
- Fixed [#24716](https://github.com/highcharts/highcharts/issues/24716), y-axis panning was limited with standalone navigator.
- Fixed [#24692](https://github.com/highcharts/highcharts/issues/24692), a custom `dataGrouping.approximation` callback was ignored on OHLC-like series after series type toggle.
- Fixed [#24754](https://github.com/highcharts/highcharts/issues/24754), a regression causing exporting not to work with Stock Tools loaded.
- Fixed [#24608](https://github.com/highcharts/highcharts/issues/24608), y-axis extremes were incorrent when using [cumulativeStart](https://api.highcharts.com/highstock/plotOptions.series.cumulativeStart).
