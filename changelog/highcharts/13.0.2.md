# Changelog for Highcharts v13.0.2 (2026-08-27)


## Bug fixes
- Fixed [#25054](https://github.com/highcharts/highcharts/issues/25054), jittered scatter points were flipped when zooming with animation.
- Fixed [#25072](https://github.com/highcharts/highcharts/issues/25072), a regression in v13.0.1 where the `package.json` module field broke UMD submodule resolution.
- Fixed [#25057](https://github.com/highcharts/highcharts/issues/25057), point markers failed to animate on series update when marker symbol was defined in plot options.
- Fixed [#22949](https://github.com/highcharts/highcharts/issues/22949), `clipPath` height was cut after chart resize in boost mode.
