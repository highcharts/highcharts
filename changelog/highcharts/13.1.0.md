# Changelog for Highcharts v13.1.0 (2026-09-18)

- Refactored `Axis.update` to reuse the elements and animate into new position, rather than destroying and rebuilding.
- Added a `className` to `chart.title` and `chart.subtitle`, so styling to these elements can be applied by custom classes.
- Extended the axis `linkedTo` option to accept another axis' id, in addition to its index.

## Upgrade notes
- The `StackItemObject.isNegative` property has been removed. Instead, check if the `total` is below 0.

## Bug fixes
- Fixed [#6967](https://github.com/highcharts/highcharts/issues/6967), y-axis labels clipped by small title offset.
- Fixed [#25090](https://github.com/highcharts/highcharts/issues/25090), CSV/XLS export produced a BOM-only file when the chart had no data.
- Fixed [#25299](https://github.com/highcharts/highcharts/issues/25299), points restored from null stayed invisible on `setData`.
- Fixed [#25095](https://github.com/highcharts/highcharts/issues/25095), regression in v13.0.0 causing touch-scrolling on several series types to block page scroll.
- Fixed [#24724](https://github.com/highcharts/highcharts/issues/24724), `useHTML` treemap data labels stayed on one line.
- Fixed [#24255](https://github.com/highcharts/highcharts/issues/24255), [tooltip.stickOnContact](https://api.highcharts.com/highcharts/tooltip.stickOnContact) made it hard to hover neighboring points if close.
- Fixed [#25050](https://github.com/highcharts/highcharts/issues/25050), for certain combinations of axis length and axis range, the point's marker was not drawn and the point had no tooltip.
