# Changelog for Highcharts v13.0.1 (2026-08-17)

- Added Dublin Core RDF metadata tag to exported SVGs with Accessibility module loaded.
- Enabled data labels for the `boxplot` series, with a new `dataLabels.alignToKey` option to align each label to a chosen value. The option is also available on range series. Closes [#23904](https://github.com/highcharts/highcharts/issues/23904).
- Added the possibility to run [`animate`](https://api.highcharts.com/class-reference/Highcharts#.animate) without an owner element.
- Added [violin plot demo](https://www.highcharts.com/demo/violin-plot).

## Bug fixes
- Fixed [#24779](https://github.com/highcharts/highcharts/issues/24779), a v13.0.0 regression that caused tooltips and other elements with `useHTML` to be affected by page-level body padding.
- Fixed [#24633](https://github.com/highcharts/highcharts/issues/24633), `Point.getZone` threw a TypeError on series with no zones.
- Fixed [#25011](https://github.com/highcharts/highcharts/issues/25011), a v13.0.0 regression causing axis and series layout not to respond to chart font size update.
- Fixed [#25001](https://github.com/highcharts/highcharts/issues/25001), a v13.0.0 regression causing missing data labels in offline PDF export.
- Fixed [#24864](https://github.com/highcharts/highcharts/issues/24864), a v13.0.0 regression causing errors in certain cases when repeatedly toggling series visibility.
- Fixed [#24805](https://github.com/highcharts/highcharts/issues/24805), empty chart update stopped processing.
- Fixed [#25045](https://github.com/highcharts/highcharts/issues/25045), regressions in v13.0.0 related to touch actions.
- Fixed [#24976](https://github.com/highcharts/highcharts/issues/24976), a v13.0.0 regression causing error on `chart.destroy` during fill animation.
- Fixed [#25030](https://github.com/highcharts/highcharts/issues/25030), a v13.0.0 regression causing scrollable plot area not to work in some cases.
- Fixed [#25034](https://github.com/highcharts/highcharts/issues/25034), outer grid line disappeared in polar charts in edge case due to float errors.
- Fixed [#24856](https://github.com/highcharts/highcharts/issues/24856), declared documented options missing or mistyped in .d.ts.
- Fixed [#24691](https://github.com/highcharts/highcharts/issues/24691), network graph data labels were not exported.
- Fixed [#24702](https://github.com/highcharts/highcharts/issues/24702), AST flattened camel case SVG tag names.
- Fixed [#22128](https://github.com/highcharts/highcharts/issues/22128), reset zoom button after pinch was not shown on mobile.
- Fixed [#24839](https://github.com/highcharts/highcharts/issues/24839), nested body element inside `foreignObject` caused conflicts with page styles.
- Fixed [#22529](https://github.com/highcharts/highcharts/issues/22529), legend item text hover style was not respected in styled mode when using the accessibility module.
- Fixed [#24471](https://github.com/highcharts/highcharts/issues/24471), all axes were represented twice in the chart `selection` event.
- Fixed [#24606](https://github.com/highcharts/highcharts/issues/24606), the `hide` method had no effect on `useHTML` elements. Also fixes [#23528](https://github.com/highcharts/highcharts/issues/23528).
- Fixed [#24844](https://github.com/highcharts/highcharts/issues/24844), attribute `borderWidth` in column series  was reset after updating the chart with the same options.
- Fixed [#24820](https://github.com/highcharts/highcharts/issues/24820), `borderRadius` was not applied correctly to the bottom corners of funnel points, and trailing null or zero points suppressed the rounding of the last visible point.
- Fixed [#24845](https://github.com/highcharts/highcharts/issues/24845), [lang.decimalPoint](https://api.highcharts.com/highcharts/lang.decimalPoint) was ignored in the exported data table.
- Fixed [#24796](https://github.com/highcharts/highcharts/issues/24796), wrong size and animation of marker symbol in horizontal `ColorAxis`.
- Fixed [#24795](https://github.com/highcharts/highcharts/issues/24795), [plotBorderRadius](https://api.highcharts.com/highcharts/chart.plotBorderRadius) clipping did not work when the Gantt module was loaded.
- Fixed [#24650](https://github.com/highcharts/highcharts/issues/24650), the accessibility [skipNullPoints](https://api.highcharts.com/highcharts/accessibility.keyboardNavigation.seriesNavigation.skipNullPoints) option skipped all points in keyboard navigation.
- Fixed [#24760](https://github.com/highcharts/highcharts/issues/24760), build errors with bundlers like Rollup caused by missing `.js` extension in import statements.
- Fixed [#22065](https://github.com/highcharts/highcharts/issues/22065), the sunburst module loaded an incomplete treemap implementation.
- Fixed [#24386](https://github.com/highcharts/highcharts/issues/24386), wrong y-axis extremes after zooming out on boosted scatter.
- Fixed [#24420](https://github.com/highcharts/highcharts/issues/24420), datetime ticks were broken after DST change.
- Fixed [#24416](https://github.com/highcharts/highcharts/issues/24416), added logic to account for scrollbar size.
- Fixed chart not correctly fitting its container in flex layouts.
- Fixed [#15368](https://github.com/highcharts/highcharts/issues/15368), broken y-axis panning in heatmap.
- Fixed [#24355](https://github.com/highcharts/highcharts/issues/24355), `package.json` was not exposing ESM entry point in the distribution package.
