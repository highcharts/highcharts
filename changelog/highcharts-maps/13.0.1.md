# Changelog for Highcharts Maps v13.0.1 (2026-08-17)

- Most changes listed under Highcharts 13.0.1 above also apply to Highcharts Maps 13.0.1.

## Bug fixes
- Fixed [#24867](https://github.com/highcharts/highcharts/issues/24867), tiled web map tiles could stay hidden when a chart or series update interrupted their fade-in animation.
- Fixed [#21909](https://github.com/highcharts/highcharts/issues/21909), panning while zooming on a tiled web map lead to wrong coordinates.
